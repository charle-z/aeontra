## Delivered behavior

P7 adds a separate **content-free JSONL** operational stream. It complements the
richer append-only audit log and cannot receive arbitrary attributes or messages.

The closed event schema covers:

- process start and stop;
- normalized HTTP request completion;
- normalized JSON-RPC request completion;
- malformed JSON-RPC batch classification;
- known public MCP tool completion and duration;
- public build identity, tool count, catalog hash, and root count.

The stream deliberately excludes prompts, request/response bodies, JSON-RPC params,
tool arguments/results, source content, paths, repository names, commands, targets,
URLs, query strings, headers, credentials, OAuth identities, usernames, email
addresses, domains, IP addresses, and raw error text.

Request identifiers are generated by the server. Client-supplied correlation values
are ignored. Timestamp and schema version are also server-owned.

## Configuration and storage

The immutable startup configuration is:

```text
MCP_DEVBOX_OBSERVABILITY=off|stderr|file|both
MCP_DEVBOX_OBSERVABILITY_PATH=<absolute private path>
MCP_DEVBOX_OBSERVABILITY_MAX_BYTES=<1048576..1073741824>
```

The default is JSONL on stderr. File mode defaults to:

```text
<primary-root>/.agent-memory/observability/observability.jsonl
```

The dedicated directory is `0700`; active and rotated files are `0600`; one `.1`
backup is retained. Existing broad directories, symlink files, symlink directories,
and symlink ancestors are rejected. Configuration/open failures stop startup before
serving and use generic path-safe errors.

In `both` mode, one failed destination does not prevent delivery to healthy
destinations. Failures are counted without retaining raw writer errors. Runtime close
failures are returned only as a generic safe class.
