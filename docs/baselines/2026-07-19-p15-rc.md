# P15 zero-touch local autopilot release candidate

Status: local release candidate only. Branch `p15-zero-touch-local-autopilot` is based
on P14 merge `54891fe7bced14e5eacace754f0072ad4d7996c2`. Do not migrate the real Parrot
device until the exact-head Linux PR checks, merge commit, automatic server deployment,
official signed Edge release and structured updater operation all succeed.

## Implemented acceptance surface

- One Ed25519-signed bundle binds Edge, model driver, autopilot worker, restricted
  updater, pinned Node 24.18.0, pinned OpenCode, provider/actions, unit, commit,
  protocol, architecture and exterior catalog.
- The reproducible signed Debian package performs atomic activation/rollback,
  preserves preferred or legacy P12-P14 state, enables rootless Podman, runs one
  preflight and starts Edge after one guided pairing action.
- Closed outbound Edge operations implement bundle status/update/rollback/repair,
  onboarding diagnosis, lab prepare/retarget and autopilot lifecycle. No public
  schema accepts a command, credential, flag, URL, path, script or caller hash.
- Every leased control operation is server-signed and verified locally. Existing P14
  identities upgrade their public control trust metadata without changing device ID
  or private device key.
- HTB action tools are absent from the exterior catalog. Legacy remote OpenCode
  runtimes reject `htb-linux`; only the local bounded-cycle autopilot can act there.
- Durable state, restart/redeploy supervision, authorization checks, STOP, storage,
  durable transient backoff, repeated-failure/action and no-progress breakers are
  covered by focused tests.
- Protected release automation builds the immutable archive/package, detached
  signatures, checksums and SPDX SBOM, then updates only the signed stable channel.

## Local verification

Passed on the Windows host:

- focused bundle, updater-contract, Edge-operation and autopilot tests;
- Linux cross `go vet ./...` and `go build ./...`;
- Linux test-binary compilation for Unix-only P15 packages;
- Git Bash syntax for every P15 shell/package script;
- actionlint 1.7.12 from its official binary after verifying published SHA-256;
- repository workflow policy, including the exact protected release exception;
- `git diff --check`.

The complete executable suite and race detector are not claimed locally. This host
has no Linux distribution/container runtime, Windows temporary-directory modes do not
represent Unix `0600/0700`, and the available temporary Go SDK cannot build the pinned
analysis tools themselves. Existing GitHub Linux jobs remain mandatory for full tests,
race, coverage, provider/TypeScript, Staticcheck, Govulncheck, CodeQL, Dependency
Review, container SBOM/vulnerability gates, Bubblewrap/rootless E2E, package migration,
restart recovery and durable jobs.

## Mandatory post-merge sequence

1. Confirm every PR check completed successfully; merge by merge commit only.
2. Confirm the existing automatic server deployment reports the merge commit and the
   98-tool catalog hash
   `sha256:108991b3eae448f60abd05e7a8b6a45f127e63ec7261766344f1b6b4df6699a8`.
3. Run the protected official Edge release workflow for an immutable `p15.x.y`.
4. Request `edge_bundle_update` with only the preserved Parrot device ID and
   `release=stable`; verify status/onboarding metadata.
5. Reuse Cap through `workspace_lab_prepare`, start one autopilot job, and report only
   safe durable metadata. A missing VPN, powered-off target or unavailable local model
   is a genuine blocker; it must not be bypassed or disguised.
