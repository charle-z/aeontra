and into small declarative modules under `internal/mcpserver/catalog`.

The resulting boundary is:

- domain modules own names, descriptions, schemas, contract versions and handlers;
- narrow service interfaces expose only the methods each module needs;
- `tools.go` composes modules and adapts them into the server-owned registry;
- aliases are declarative and reuse the exact target schema, handler and policy path;
- annotations are declarative and preserve truthful read/write/destructive/open-world
  posture;
- an AST test rejects direct `Server.add` registration and legacy schema helpers in
  `tools.go`.

approval path, environment variable or catalog hash changed.
