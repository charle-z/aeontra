## P4 result

P4 applied targeted Layer-1 hardening without adding approvals to normal repository
work or changing the public MCP catalog:

Security index: path-qualified command spoofing; workspace-controlled executable;
grant TTL; pending access requests; audit file paths; HTTP JSON-RPC batches.

1. **Path-qualified command spoofing:** `./git`, parent/absolute/drive-qualified
   paths, and whitespace-disguised program names cannot impersonate an allowlisted
   executable. Always-blocked shells retain their destructive classification.
2. **Trusted executable resolution:** bare allowlisted names resolve once to canonical
   absolute paths; relative results, symlinks into a workspace, and any
   workspace-controlled executable are rejected before execution.
3. **Grant TTL authority:** the policy core, not only the HTTP adapter, enforces the
   five-minute default and the one-second to one-hour accepted range.
4. **Pending access requests:** requests expire after 15 minutes, are capped at 256,
   prune expired state, and deduplicate identical path/raw requests without merging
   normal and raw authority.
5. **Documentation state:** the completed Layer 1 spec/tasks, constitution, capsule,
   roadmap, README, AGENTS, and handoff were synchronized and protected by tests.
6. **Audit file paths:** Args, Error, and every Files entry are redacted independently
   before JSONL persistence.
7. **HTTP JSON-RPC batches:** batches are parsed incrementally, empty arrays are
   invalid, and processing stops after 128 items with one bounded error response.
